プライバシーポリシー

対象アプリ:メール下書きツール260827
施行日:2026年10月2日

1. 本アプリについて

「メール下書きツール260827」(以下「本アプリ」)は、開発者本人が自分のWindowsパソコン上だけで使う個人用のデスクトップツール(Python製)です。 一般には提供しておらず、開発者本人以外の利用者はいません。

2. アクセスするデータ

本アプリは、開発者本人のGmailアカウントに対してのみ、Gmail APIのスコープ https://www.googleapis.com/auth/gmail.modify を使用し、次のデータにアクセスします。

  • メールの下書きの作成
  • 返信の受信有無・送信済みかどうかの確認のための、開発者本人のメールボックスの検索
  • 上記の確認に必要な、メッセージのヘッダー(件名・宛先・日時など)および本文の読み取り

3. データの利用目的

取得したデータは、上記2に記載した機能(下書きの作成、返信・送信状況の確認)を実現する目的にのみ利用します。 広告、分析、マーケティング、その他の目的には利用しません。

4. データの保存

  • 取得した情報や処理結果は、開発者のパソコン内のExcelファイルおよびログファイルにのみ保存されます。
  • クラウド上のサーバーやデータベースは使用していません。アクセス解析ツールや広告も使用していません。
  • OAuthの認証トークンも、開発者のパソコン内にのみ保存されます。

5. 第三者への提供・共有

取得したGoogleユーザーデータを、第三者に提供、販売、共有、移転することはありません。 また、AI・機械学習モデルの学習にも利用しません。

6. Google APIサービスのユーザーデータに関するポリシーへの準拠

本アプリによるGoogle APIから受け取った情報の利用および他のアプリへの移転は、限定的使用(Limited Use)の要件を含め、 Google API サービスのユーザーデータに関するポリシー(Google API Services User Data Policy) に準拠します。
The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. データの保持と削除

  • パソコン内に保存されたファイル(Excelファイル、ログ、認証トークン)は、開発者が自分で削除します。削除すれば、本アプリが保持するデータはなくなります。
  • Googleアカウントへのアクセス許可は、いつでも https://myaccount.google.com/permissions から取り消すことができます。

8. ポリシーの変更

本ポリシーは、必要に応じて改定することがあります。改定した場合は、このページに掲載し、施行日を更新します。
